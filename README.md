# Arabic-English AI Receptionist

This repository currently contains the Phase 0 engineering foundation for a production-style portfolio project. It provides a small FastAPI application, PostgreSQL readiness plumbing, SQLAlchemy/Alembic setup, and development/CI tooling.

Customer operations, AI behavior, messaging, voice, booking, CRM, and operator UI features are future phases and are not implemented here.

See `docs/development/setup.md` for local setup and `docs/roadmap.md` for the approved phase plan.
