# Canonical roadmap

This is the approved 13-phase roadmap for the Arabic-English AI Receptionist & Customer Operations Agent portfolio project. The project is a production-style portfolio implementation, not a SaaS startup. Phase 12 is the fixed finish line.

| Phase | Name | Status |
| --- | --- | --- |
| 0 | Engineering Foundation & Architecture | `COMPLETE` |
| 1 | Business Domain, Identity & State | `NOT STARTED` |
| 2 | Booking & Deterministic Business Tools | `NOT STARTED` |
| 3 | HubSpot CRM Integration | `NOT STARTED` |
| 4 | Conversational Core & Text Evaluation Baseline | `NOT STARTED` |
| 5 | WhatsApp Text & Voice Notes | `NOT STARTED` |
| 6 | Vapi Realtime Voice & Speech Evaluation | `NOT STARTED` |
| 7 | Omnichannel Customer Operations | `NOT STARTED` |
| 8 | Human Handoff, Reliability & Security Hardening | `NOT STARTED` |
| 9 | n8n Asynchronous Operations | `NOT STARTED` |
| 10 | Operator Dashboard & Observability | `NOT STARTED` |
| 11 | Multilingual System Evaluation & Release Gates | `NOT STARTED` |
| 12 | Portfolio & Freelance Release | `NOT STARTED` |

Phase 0 was independently reviewed and approved as `COMPLETE`. Phases 1–12 remain `NOT STARTED`, and no Phase 1 behavior is included in this branch.
